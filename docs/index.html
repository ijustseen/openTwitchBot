OpenBot

Окно на вашем компьютере сидит в чате Twitch и отвечает на команды вроде !hello. Что делает команда, решает обычный файл Python.

С чего начать

  1. 1
    Откройте окно

    Дважды щёлкните OpenBot.app или OpenBot.exe. Из исходников: Python 3.11+, затем команды ниже.

  2. 2
    Войдите через Twitch

    Кнопка в шапке. Аккаунт, который войдёт в браузере, и будет писать ответы в чат.

  3. 3
    Укажите канал и нажмите «Старт»

    В поле «Канал» — чей чат слушать, без решётки. Когда статус станет «В сети», бот уже в чате.

  4. 4
    Добавьте команду

    «Новая команда», триггер вроде !hello, текст скрипта, «Сохранить». В чат можно писать сразу.

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py

На Windows окружение включается командой .venv\Scripts\activate. Сами команды выполняет Python на компьютере, даже если окно собрано в приложение.

Вход

Один раз в консоли Twitch

На dev.twitch.tv/console/apps зарегистрируйте приложение. Redirect URL вставьте точно: http://localhost:17563/callback. Категория — Chat Bot. Client Secret Twitch показывает один раз.

Потом в окне

«Войти через Twitch», Client ID и Client Secret, затем «Открыть браузер и войти». В шапке появится «Аккаунт: ник». Ник и токен вручную вводить не нужно.

Чей аккаунт. Свой аккаунт канала подходит: ответы идут от вашего ника. Отдельному аккаунту бота нужен модератор, иначе режим «только для фолловеров», «только для подписчиков» или медленный режим может спрятать его сообщения. Когда токен истечёт, окно обновит его само, пока доступ не отозван в настройках Twitch.

Команды

Команда — функция run(ctx). Сообщение !hello мир попадает в команду !hello, слово «мир» — в ctx.args. Регистр команды не важен. «Сохранить» действует сразу, даже если бот уже в сети.

Список слева

Переключатель выключает команду и оставляет её на месте. Щелчок по строке открывает её в редакторе.

Кнопки справа

«Проверить» гоняет скрипт без отправки в чат. «Вставить» добавляет код из буфера. «Для нейросети» копирует инструкцию, чтобы модель написала команду в нужном виде.

Кулдаун

Общий на команду, а не на каждого зрителя. Пустое поле — без паузы.

Кто может вызвать

«Модераторы и стример» пускает модераторов и владельца канала. Остальные до скрипта не доходят.

«Проверить» подставляет пользователя tester, аргумент пример, владельца канала — да, модератора — нет. «Удалить» убирает команду и файл скрипта.

Что есть в ctx

Для сообщения !hello мир всем от зрителя CoolUser на канале mychannel:

ПолеЧто внутри
ctx.userОтображаемое имя, CoolUser
ctx.user_idЧисловой id Twitch. При смене ника не меняется
ctx.argsСлова после команды: ["мир", "всем"]. Без слов список пустой
ctx.messageВся строка: !hello мир всем
ctx.channelКанал из настроек, строчными и без решётки
ctx.is_modМодератор или владелец канала
ctx.is_broadcasterТолько владелец канала

ctx.reply("текст") пишет в чат. Можно вызвать несколько раз: уйдут первые 5 непустых ответов, каждый до 500 символов. print(...) виден только в логе окна.

def run(ctx):
    if not ctx.args:
        ctx.reply(f"@{ctx.user}, напишите имя после команды")
        return
    ctx.reply(f"{ctx.user}: {' '.join(ctx.args)}")

Как выполняется скрипт

Команда запускается отдельным процессом Python и обрывается примерно через 10 секунд, чтобы ошибка не закрыла окно. run нельзя делать async. Песочницы нет: скрипт может читать файлы, ходить в сеть и запускать программы от вашего имени. Токен Twitch в команду класть не нужно.

Инструкция для нейросети

Кнопка «Для нейросети» в окне копирует тот же текст. Вставьте его в чат с моделью перед просьбой написать команду.

Ты пишешь команду для локального Twitch-бота OpenBot.
Команда — это один файл Python с функцией run(ctx). Функция обычная, не async.

Что приходит в ctx, когда зритель пишет в чат, например, «!hello мир всем» на канале mychannel:
- ctx.user — отображаемое имя автора, с тем регистром, как в чате.
- ctx.user_id — числовой id Twitch. Ник можно сменить, id нет.
- ctx.args — список слов после команды. Для примера выше это ["мир", "всем"]. Самой команды в списке нет. Если слов нет, список пустой.
- ctx.message — вся строка целиком, вместе с командой: "!hello мир всем".
- ctx.channel — имя канала из настроек бота, строчными буквами и без решётки: "mychannel".
- ctx.is_mod — True у модератора и у владельца канала. У обычного зрителя False.
- ctx.is_broadcaster — True только у владельца канала.

Как отвечать:
- ctx.reply("текст") отправляет строку в чат. Вызов можно повторить: в чат уйдут первые 5 непустых ответов.
- Каждый ответ схлопывается в одну строку и обрезается до 500 символов.
- print(...) в чат не попадает. Это строка в лог окна OpenBot.

Правила кода:
- Обязательна функция run(ctx). Другие функции рядом можно.
- Не используй async и await.
- Не импортируй twitchio и не трогай окно программы. Доступны обычные модули Python.
- Скрипт обрывается примерно через 10 секунд.
- Песочницы нет: скрипт может читать файлы и ходить в сеть от имени пользователя. Не проси вставлять в команду токен Twitch и пароли.
- Если команда в окне стоит в режиме «Модераторы и стример», обычный зритель до run(ctx) не доходит. ctx.is_mod внутри скрипта нужен, когда команда доступна всем, а ответ модератору другой.

Пример:

def run(ctx):
    if not ctx.args:
        ctx.reply(f"@{ctx.user}, напишите имя после команды")
        return
    ctx.reply(f"{ctx.user}: {' '.join(ctx.args)}")

Когда пользователь просит команду, верни полный файл, который можно сохранить как есть.

Где что лежит

Рядом с программой появляется папка data. В data/config.json канал, токен и список команд. Сами скрипты — в data/commands. Файл с токеном в git не попадает. У собранного приложения на macOS эта папка лежит рядом с OpenBot.app, на Windows — рядом с OpenBot.exe.

Сборка и обновления

На macOS получается приложение для Mac, на Windows — для Windows. Обе системы на одном компьютере не собрать. Релиз на GitHub появляется после тега v*: туда кладутся zip для macOS (Apple Silicon) и Windows.

Собранное окно с номером версии само смотрит последний релиз. Полоска «Доступна версия» предлагает «Обновить»: архив скачивается, программа перезапускается, папка data остаётся. Запуск через python main.py обновления не ставит. У версии 0.1.1 этой кнопки ещё нет.

Код OpenBot под лицензией MIT: им можно пользоваться и делиться, если сохраняется уведомление об авторстве CnoLvaN.

Первый запуск на Mac. Сборки не проходят проверку Apple: для этого нужен платный сертификат Developer ID. Если система пишет, что не удалось подтвердить отсутствие вредоносного ПО, нажмите «Готово», затем «Системные настройки» → «Конфиденциальность и безопасность» и внизу «Всё равно открыть» рядом с OpenBot. На Windows SmartScreen предупредит, что издатель неизвестен.
